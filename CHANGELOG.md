# Changelog

## 1.0.0

First public release.

- Record a click-through or build the steps by hand; replay them interactively or unattended (`--run`).
- Find elements by their text (contains, starts with, ends with, exactly, wildcard, regex) instead of CSS selectors.
- Loops over links (with pagination and ranges), over page elements and over a hand-written link list; conditions and variables.
- Human-like mouse paths, random clicks, pauses; end a wait when the page changes or a text appears.
- Handling of advertising windows, popups, hand-overs and file downloads.
- Optional uBlock Origin integration, history, browser-wide zoom, English and German interface.
- Collect links into a results list (CSV export) and send them to JDownloader.
- Two example plans in `examples/` to start from.
